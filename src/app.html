分析中

即時網上搜尋（需要你自己的 API 金鑰）

安裝版會直接由你的手機連接 Anthropic 的 Claude API，使用其網上搜尋工具，並打開最多 6 個官方或原始網頁讀取全文核對關鍵數字。金鑰只保存在這部手機的瀏覽器內，不會傳送到其他地方。每次分析約進行 8–15 次搜尋，費用視模型、搜尋次數和讀取的網頁長度而定，請在 Anthropic Console 設定每月用量上限。

這個應用程式做得到與做不到的事

  • 它不能搜尋「所有」公開資訊。每次分析只會檢索十多個搜尋結果，結論只會引用實際檢索到的頁面；未被檢索到的網址會被自動刪除，不會出現在報告中。
  • 「置信度」是 AI 根據證據質素作出的推理估計，不是統計概率。數字只用來比較建議之間的把握程度。
  • 每個來源都會標示類型（官方、智庫、學術、媒體、商業、網上輿論）及可能的利益衝突，例如院校推廣進修、金融機構推廣產品、培訓機構推廣課程。
  • 它不會推介個別股票、基金或保險產品；涉及法律、稅務、移民或醫療的決定，請向持牌專業人士確認。
  • 涉及政治或意識形態的選擇，它只分析對你個人的實際利弊與風險，不替你選邊。

安裝到手機

  • iPhone：用 Safari 開啟網址 → 分享按鈕 → 「加入主畫面」。
  • Android：用 Chrome 開啟網址 → 右上角選單 → 「安裝應用程式」或「加至主畫面」。
